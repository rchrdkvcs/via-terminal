# One window per instance for now

- Status: accepted
- Date: 2026-10-02

Via runs a single instance with a single window; launching it again focuses that window. Multi-window support (ADR-0003) cost a cross-window ownership protocol in every organization command while nobody could use the basics comfortably. It can return once the single-window experience is solid; the frontend keeps organization state per window to leave that door open.
